# blog
Lista de Tareas - LAB El Sitio del Blog

Tarea 1: Configuración del repositorio
Crear un nuevo repositorio si no existe
Tarea 2: Menú de navegación funcional
Crear navegación que enlace a las 3 páginas:
Inicio
Quiénes somos
Contacto
La navegación debe ser sticky (visible al hacer scroll)
Debe aparecer en todas las páginas
Tarea 3: Pie de página funcional
Incluir lista de autores del sitio (nombres del equipo)
Agregar correos electrónicos falsos
Información de contacto falsa
Nombre del proyecto
Debe aparecer en todas las páginas
Tarea 4: Página de Inicio
Elegir un tema para el blog
Escribir contenido usando etiquetas correctas (h1-h6, p)
Insertar imágenes (img)
Estilizar con CSS (colores, layout texto-imagen)
Tarea 5: Página Quiénes Somos
Escribir sobre el grupo
Explicar por qué existe el sitio web
Tarea 6: Página de Contacto
Información de contacto falsa (emails, teléfonos)
